## 3. Cesium 地图怎样支持挖土

### 3.1 三条路线比较

| 路线 | 能力与代价 | 本次选择 |
|---|---|---|
| Cesium 背景 + 独立可挖土区 | 复用现有切削；需要地图遮挡处理、坐标对齐和独立碰撞 | **推荐，进入月底计划** |
| 提取施工范围为本地可编辑地形 | 可更接近原始地表；需处理数据获取、采样、接缝、模型空洞与更新 | 后续增强；本月只允许小范围初始高度采样验证，不做通用转换工具 |
| 直接修改流式地图瓦片 | 需处理瓦片加载卸载、多级细节、网格重建、碰撞重建和修改持久化 | 不纳入本月，不能按“加一个脚本即可挖”估算 |

推荐路线下，坑槽是真实改变本地地形与其碰撞面；Cesium 原始数据本身不被改写。工程表达应明确称“地理定位的局部挖掘仿真”，不能宣称编辑了在线地图源数据。

### 3.2 地图渲染和物理地面分别处理

Cesium 官方明确说明，Cartographic Polygon 的裁剪属于材质视觉效果，**不会改变物理网格**，隐藏区域仍可能碰撞。[Cesium 区域裁剪说明](https://cesium.com/learn/unity/unity-clipping/)

本次采用以下工程设计，实施后必须实测：

1. 锁定一个施工范围，将其中原地图表面视觉裁剪，给局部可挖土层留出空间；不能只在原地图上盖一层薄土，否则挖深后原地面会露出或挡住坑槽。
2. 月底单工位场景中的背景 tileset 关闭 `createPhysicsMeshes`，由项目本地作业区承担机械接触。该选项是**整个 tileset** 的配置，不是局部裁剪碰撞开关。[Cesium3DTileset 接口](https://cesium.com/learn/cesium-unity/ref-doc/classCesiumForUnity_1_1Cesium3DTileset.html)
3. 本地作业区提供：履带承重平台、可挖 Terrain、实体底板、必要的边界和障碍碰撞体，以及车厢碰撞。承重平台不能铺满挖坑区域，否则又会产生隐形阻挡。
4. 承重平台与土区放在同一施工坐标框架内，衔接处不能存在缝隙、重叠承重面或初始穿透。超出已建物理范围不允许驾驶；背景建筑不自动具备阻挡能力。
5. 需要在地图其他区域行驶时，另做碰撞分区或本地碰撞网格提取方案。本月不临时扩大到全地图行驶。

如果项目还有多个地形/模型 tileset 覆盖施工区，必须逐一处理视觉重叠和碰撞，不只配置其中一个。当前项目 manifest 未直接声明 Splines；执行多边形裁剪前核实依赖是否可用并补齐。具体材质兼容性在实际地图上验证。

### 3.3 坐标、土层初始化和流式加载

- 在任务开始前，将 Cesium 地理原点放在施工点附近，使机械、土区和车厢在小范围米制坐标中工作。记录施工点经纬度、高度基准、朝向和偏移；不能把不同来源的海拔值不加核对地混用。
- 任务执行期间固定原点，停用自动原点移动和施工子场景切换。`CesiumOriginShift` 会随对象距离移动原点，距离设为 0 表示持续移动，**不是关闭**。[CesiumOriginShift 接口](https://cesium.com/learn/cesium-unity/ref-doc/classCesiumForUnity_1_1CesiumOriginShift.html)
- 当前 `DeformableSoilTerrain` 要求世界旋转为零、缩放为一。通过施工点地理原点和初始化坐标对齐满足该要求，不能任意旋转/缩放现有 Terrain 或在运行中移动父级来追地图。
- 土区先复用约 6 × 6 m、129 × 129 的高度场。初始高度可来自已确认的本地高程数据或一次性地图表面采样；若先人工拟合平台，必须标记为简化地形，不声称测量级一致。
- 地图只提供初始表面参考；可挖厚度、最低高度、土壤密度由任务参数指定。采样应在加载完成后进行，并排除屋顶等不适合作为土面的对象。
- 作业开始后，土层几何和土量状态独立保存；地图切换细节、卸载或重载不得重置坑槽。相机远近切换后仍需验证无原始地表穿出。
- 数据源若仍是未经处理的 OSGB，先验证实际加载链路与样本，不把“已安装 Cesium”当作所有 OSGB 已经可直接导入。本月不新建通用 OSGB 转换平台。

### 3.4 地图接入通过条件

地图接入是本次新增待验收项：机械与地面位置正确；施工区域能看到真实坑槽；挖深后不被原始地图碰撞挡住；相机改变视角和地图细节后坑槽不恢复；本地机械不因原点变化跳动；地图加载失败有明确提示。

保留无 Cesium 的独立切削场景作为故障定位和断网演示基线，但它**不能代替地图接入验收**。18 日前地图方案不能成立时，必须登记地图项未完成并重估交付，不可静默删项。在线数据不默认允许离线打包；桌面包须按实际服务权限验证加载，保留必要署名，文档与日志不记录访问令牌。

## 4. 从切削原型到自主挖装

### 4.1 先收敛真实切削

复用 `DeformableSoilTerrain.cs` 和 `BucketSoilCutter.cs`，不重新创建另一套同职责组件。切削依据实际斗尖位移和切深，不依据目标关节角“假设已经挖到”。

18 日前补足非切削面过度穿入、满斗继续推进和底部约束。简化阻力必须有上限且反向于切削运动，不在静止时凭空注入能量。若连续土力模型不稳定，可用有限驱动力、切深/速度限制和检测后停止推进收敛范围，但不能允许任意穿土而称作通过。暂不要求土壤破碎、侧壁坍塌或精确土力学。

### 4.2 土方账本、载荷和卸料

统一使用 m³，暂不考虑松胀，遵守：

`累计地形减少量 = 当前斗内量 + 车辆净增量 + 累计洒落量`

当前高度场采用网格四角均值积分约定；这是模型计量口径，不宣称等同真实土方测量或所有碰撞三角形的精确体积。独立重算初始与当前高度图，核验增量账本。

卸料必须同时满足开斗姿态、有效出料位置及落料路径条件，按车厢剩余容量接收；车外部分计为洒落。不能在动画结束时直接把斗量全部加到车里。斗内土和车厢填充仅显示账本结果。

等效载荷采用一种经验证的质量方案，避免与额外重力重复计算；限制变化频率和幅度，检查空、半、满斗。它仍是简化载荷，不输出真实挖掘力结论。

### 4.3 有反馈的自主状态机

任务校验 → 选可达挖点 → 接近 → 切削/收斗 → 抬升 → 回转 → 卸料确认 → 返回 → 更新挖点，直至满足结束条件。

先登记有限的可达候选点和低速搬运通道，使用受限关节搜索或简化逆解，并以实际斗尖误差校验。不是播放固定动画，也不要求本月训练模型。

| 情况 | 必须执行的逻辑 |
|---|---|
| 实际姿态与速度满足阶段条件 | 才推进下一阶段 |
| 空挖或装载不足 | 标记该点，换点重试，连续失败最多 2 次 |
| 动作超时、受阻或无进展 | 停止推进；仅在已验证通道可用时退避，否则保持并报故障 |
| 未卸净 | 在有效位置补充开斗一次，仍失败则停止 |
| 达到目标量、车满、可达区域挖尽 | 停止继续挖土，在安全条件下回待机并记录原因 |
| 车不存在、目标不可达或地图施工配置无效 | 启动前拒绝任务 |
| 人工接管/停止 | 停止自主目标推进，保持机械受控；不能靠关闭全部物理冒充停止 |

关节驱动只保留一个写入方；任务控制器提交目标并读取反馈。日志记录阶段、实际姿态、土量、耗时、失败次数和终止原因。

- [ ] **地图融合：** 指定施工点正确显示；原地图不遮住坑、不形成隐形碰撞；地图细节变化后土量和坑槽保持；任务中原点固定，机械无坐标跳变。地图加载失败有提示，桌面包的实际数据访问经过验证。
- [ ] **真实挖土：** 地形产生可测量坑槽；抬斗、空扫、满斗和越界不凭空删土；底面和非切削面过度穿入受到约束。
- [ ] **完整装车：** 切削、保持、卸料和车厢接收形成闭环；车外卸料计洒落，容量不足不得超装，填充显示随账本变化。
- [ ] **自主作业：** 一次启动连续完成 20 个有效装车循环，不逐斗人工控制，跨至少 3 个可达挖点。单斗有效量至少为斗容量 10%，每斗车内增量至少为卸料前斗量 90%；初始土量和车容须足够。
- [ ] **随地形决策：** 地形改变后更新挖点或切深；另外验证 2 种土层高度和 1 个预先登记的可达车位偏移，不要求任意场景泛化。
- [ ] **守恒：** 独立高度场积分与斗内、车内、洒落总量之差不超过 `max(累计挖出量 × 1%, 0.001 m³)`；无负数、超容量或重复计量。该指标仅表示模型内部一致性。
- [ ] **停止与异常：** 目标量、车满、挖尽分别验证；不可达、阻挡、连续空挖和卸不净必须有限重试或故障停止，无无限等待；人工接管有效。
- [ ] **重复性：** 标准任务从干净重置至少重复 3 次，每次 20 个有效循环，记录全部成功和失败；重置恢复地形、土量、任务与机械初始化。该样本不构成真机可靠性证明。
- [ ] **性能与交付：** 目标桌面环境平均 ≥30 FPS 为原型指标，记录帧时间 P95、最大卡顿和物理步耗时，无持续物理积压或机械爆飞；交付工程、桌面包、配置、录像和已知限制。

## 8. 风险触发与处理

| 时间/风险 | 处理原则 |
|---|---|
| 16 日数据源或施工点无法确定 | 立即记录地图集成阻塞；本地物理继续开发，但不能把未验证地图写成已完成 |
| 18 日门槛 A 未通过 | 限定平整小工位和低速轨迹，停止美化与新数据集接入；地图或接触仍失败则明确月底整体交付高风险 |
| 21 日单斗自动闭环未通过 | 集中修复账本、卸料和执行反馈，固定一个车位；不增加训练或语言入口 |
| 23 日自主多轮/停止未通过 | 取消全部增强项，保留有限可达点自主换点；仍失败则登记核心延期风险 |
| 24 日冻结门槛未通过 | 形成未通过项清单，28 日优先处理阻塞；不得把 25—27 日改为隐含工作日，也不得保证原范围必然按时完成 |
| 地图材质裁剪无效或仍有碰撞 | 检查实际材质与全部重叠 tileset；拆清视觉和物理，不能只关渲染宣称开挖通过 |
| 土阻力/载荷引起抖动 | 限制推进速度、切深、力和载荷变化，复测质量惯量；不靠无限驱动力或瞬移过关 |
| 数据加载或打包不稳定 | 24 日前做桌面烟测；保留独立基线定位故障，地图验收失败如实记录，不用无地图场景代替 |

月底不能同时保证高真实性土力学、任意地图施工、自主导航与挖装闭环。核心目标仍是地图指定工位中的真实坑槽、守恒计量和有反馈的自主装车；无法达到时需明确延期或部分交付。
