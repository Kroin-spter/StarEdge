# ZX200 底盘物理使用说明

更新：2026-09-15。范围：Unity 内置物理下的简化履带行驶，不包含逐节履带、真实土壤抓地标定或自主导航。

## 使用方法

1. 使用 `Assets/Robotics/zx200_description/Prefabs/zx200.prefab`。本次预制体已开启移动模式并挂载 `Zx200TrackDrive`。
2. 场景地面必须有非触发器 Collider，且属于键盘组件 `groundLayers` 包含的层。将履带放在地面附近，避免设备初始嵌入地面；不再通过射线将设备吸附到地面。
3. 进入 Play 模式，聚焦 Game 窗口。W/S 前进、后退；A/D 左转、右转；松开行驶键后制动。Q/E 仍为上车体回转，大小臂与铲斗按键沿用原设置。
4. `Zx200KeyboardController.fixedBase` 关闭时是动态行驶模式，开启时锁定底盘，供定点挖掘调试。场景实例若曾单独覆盖该字段，需要取消对应覆盖或手动关闭该字段。
5. 设备在无碰撞地面的场景中会下落，这是动态底盘的预期行为。相机继续跟随实际履带根节点。

原有当前场景和未保存对象不由本次配置工具覆盖；预制体修改通过 Unity 的正常引用机制应用。

## 实现与参数

原有履带碰撞网格负责承重及阻挡障碍。左右两侧各三个近地检测点向接地平面施加受限牵引力，差速输入产生偏航；侧向力近似履带抓地。无有效接地时不提供行驶牵引，重力、惯性与普通碰撞继续生效。

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `moveSpeed` | 2 m/s | 前后行驶目标速度，实际速度受接触与负载影响 |
| `turnSpeed` | 35 °/s | 用于计算左右履带速度差的偏航目标，非保证转速 |
| `responseTime` | 0.4 s | 速度误差反馈响应时间 |
| `maxAcceleration` | 3 m/s² | 纵向牵引和制动反馈的加速度上限 |
| `tractionCoefficient` | 0.8 | 近似抓地力上限系数，尚未标定 |
| `lateralGrip` | 2 /s | 横向速度阻尼系数 |
| `contactTolerance` | 0.06 m | 履带底部附近的接地检测容差 |
| `maxGroundAngle` | 45° | 接地法线筛选上限，不等于已验证爬坡能力 |
| `commandTimeout` | 0.25 s | 本地行驶请求中断后的制动超时 |

运行时有行驶输入时为履带接触使用低摩擦材质，切向抓地由履带组件补充；无行驶输入时改用摩擦系数默认 0.9 的驻车材质，抑制摆臂和回转反作用引起的底盘滑转；车体、机械臂、铲斗碰撞保持原配置。该模型按整机质量均分近似支撑载荷，不求解真实履带张紧、土壤沉陷或复杂地形牵引。初版验证范围为平地与 8° 缓坡，不承诺跨沟、攀越高台阶或极端坡面稳定性。

键盘行驶输入优先于 AZ 履带输入。AZ 行驶帧超过 0.5 秒没有更新时停止使用该行驶指令，发送端应周期发送；原有关节主题输入行为保持不变。停止提供制动力而非立即清零速度。固定模式切换是仿真调试锁定功能，不能作为真实驻车制动的物理标定。

## 验证方法

新增 `Assets/Tests/PlayMode/Zx200TrackPhysicsTests.cs`，使用完整 ZX200 预制体检查前进/制动/倒车、双向转向、撞墙阻挡、无地面下落与无空中牵引、缓坡上行、指令中断与固定模式。原有关节和铲斗测试显式使用固定模式，避免无地面测试夹具因新的默认移动模式而下落。

EditMode 测试检查移动请求不直接改位置，以及预制体重复配置时只有一个履带组件、底盘启用重力且可移动。底盘扩展不等于自主导航完成，也不代替地形切削和土方装车的后续实现。

## 本次验证结果

2026-09-15，在 Unity 6000.5.10f1 的隔离工程中完成 72 项 EditMode 和 12 项 PlayMode 测试，全部通过；同步后的源码和预制体已与测试副本逐文件核对。结果保存在 [EditMode.xml](测试结果/2026-09-15-底盘物理/EditMode.xml) 和 [PlayMode.xml](测试结果/2026-09-15-底盘物理/PlayMode.xml)。

验证使用完整设备预制体、平面碰撞地面及 8° 缓坡；没有覆盖用户当前未保存场景中的全部物体组合。未执行桌面或 Web 发布构建。

实现所用物理接口可参阅 Unity 官方 [ArticulationBody.AddForceAtPosition](https://docs.unity.cn/ScriptReference/ArticulationBody.AddForceAtPosition.html)。
