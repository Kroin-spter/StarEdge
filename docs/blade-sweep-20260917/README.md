# 齿尖切削与进斗分离

本轮针对主场景 `Assets/Scenes/sence_test.unity` 修正两个问题：旧的 0.5 m 圆盘扫掠会在铲斗前方提前切土；旧的进土角度门槛会把有效竖直切入也拒绝掉。

## 当前模型

- 斗齿标记 `tipMarker` 与导入网格真实最前齿尖相差约 6 mm，本轮没有平移铲斗。
- 切削使用铲斗局部校准的薄刃箱体及其两帧之间的扫掠，替代运行时圆盘半径。选中铲斗或勾选 `showCuttingGeometry` 可以看到青色齿尖代理线框。
- 新土层使用 513×513 高度图，6 m 区域采样间距约 11.7 mm；这是为了避免 3 cm 刃厚落在高度图采样行之间。原始 129 分辨率高度通过插值保留，原资源备份在 `/home/sk/Unity/blade-sweep-backup-20260917-181705`。
- 切削、进斗和保土分开计算。竖直齿尖运动可以切削；斗口相对运动决定收进多少，剩余切出土沿铲斗两侧进入下落账本，再由碰撞决定回填或撒落。
- `ExcavatedVolumeM3 = CollectedVolumeM3 + DisplacedVolumeM3`。界面同时显示累计切出、累计进斗和切削侧落。
- 阻力使用深度、切削宽度、土重度、黏聚力、内摩擦角、速度的连续近似，参考被动土压力/土方方程的结构；参数未由实测标定，不能当作完整 Reece、DEM 或液压负载模型。

## 操作

主场景初始斗口用于观察，推荐先在空中调整姿态，再接近土层：`H` 收斗、`R` 降动臂、`G` 收斗杆切入；`F` 抬升退出；`E` 向右前方车厢回转，`Y` 翻斗卸料，`Backspace` 复位。

状态中的“刃口切削”表示 Terrain 已发生实际高度变化；“进斗 xx% / 其余侧落”表示本次切出的土没有全部进入斗内。竖直切入看到进斗量较少是预期行为，不代表没有挖到土。

## 验证

- EditMode 最终：133 项通过，0 失败，见 `blade-edit-final.xml`。
- Rendered PlayMode 最终：12 项通过，0 失败，见 `blade-play-final.xml`。包括真实主场景竖直切入、抬升退出、主场景装车/回填、旧 Demo 和连续阻力测试。
- 主场景竖直切入实测：切出 0.008502 m³，进斗 0.007649 m³，侧落 0.000853 m³；入口位置 `(330.10, 8.28, 406.15)`，抬升后成功退出。
- 主场景一斗装车实测：累计切出约 0.086863 m³，车厢接收 0.082808 m³，回填 Terrain 0.003745 m³，独立撒落 0.000309 m³，斗内和下落中归零。
- 测试先验证缺失 API 和错误旧行为确实失败，再验证通过；证据文件保留在本目录。

## 边界

Terrain 仍是高度图：只能表示每个水平坐标一个表面，不能表达洞穴、悬挑和颗粒坍塌。薄刃的切削代理仍受高度图网格分辨率影响；极细于采样间距的运动可能无新体素可改。切削侧落是有账本的简化土流，不是离散元颗粒模拟。

本轮没有修改 Cesium 3D Tiles 原始文件，没有重新导出 Web，也没有加入 VFX Graph。所有主项目代码、测试和局部土层资源在同步前都做了备份和字节校验。
