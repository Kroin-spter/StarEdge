# 主场景动态履带底盘

## 修改

主场景 `Assets/Scenes/sence_test.unity` 的 `Zx200KeyboardController.fixedBase` 改为 false，施工场景生成器采用相同配置。复用现有 `Zx200TrackDrive`：左右履带各三个接地点施加有限牵引力；ArticulationBody 与地面碰撞承担支撑；松键使用制动和停车摩擦。挖掘期间底盘仍为动态刚体，没有停车后自动固定。

## 使用

退出 Play 后重新载入 `sence_test`，等待 Unity 导入完成再运行；如果编辑器提示场景有未保存修改，请保留自己的修改，核对挖掘机 Keyboard Controller 上的 Fixed Base 已取消勾选。点击 Game 窗口获得键盘焦点。

- W/S 或上下方向键：前进、倒车。
- A/D 或左右方向键：底盘左右转向。
- 松开行驶键：制动。
- Q/E：上车回转，与底盘转向独立。
- H/Y 收斗/翻斗，R/F 降臂/抬臂，G/T 收斗杆/伸斗杆。

先抬斗行驶到土区附近，再停车切入、收斗、抬升。当前可挖区域仍是局部 Terrain；行驶到其他 Cesium 表面不会把它变成可挖土层。Backspace 清空土方并恢复土层，不会把行驶后的底盘送回起点。

## 验证范围

新增 `MobileMainSceneTests.DrivesThenExcavatesWithDynamicBase`：在真实主场景前进约 0.4 m，检查接地和制动，再收斗、抬升，检查动态状态、底盘漂移、倾角和土量守恒。原有履带测试覆盖前进、倒车、左右转向、缓坡、障碍、失去地面、指令超时与固定模式。原有主场景测试验证竖直切入、装车和回填。

验证环境使用主项目原版 zx200 预制体与当前脚本；结果以本目录最终 XML 为准。这里只验证施工平台和测试坡面，未验证任意 Cesium 地形通行。履带采用简化接触力模型，没有逐节履带运动。本轮没有重新构建 Web。
