# 自由卸土、重力土面与 Terrain 回填

## 打开与操作

单独打开 `Assets/Robotics/zx200_description/Demos/SoilCutting/Demo 3/ZX200SoilDemo.unity`，Play 后等待初始姿态稳定。

1. F 降低动臂，出现斗量后停止切削。
2. Y 收斗，再用 R 抬升。土面会按重力和安息角在斗腔内调整；姿态不够收拢时会撒土。
3. 原地 H 翻斗：无需指定接收区，土会下落，落回可挖 Terrain 后抬高地形。
4. 或先 Q 回转约 45 度到青色平台，再 H 翻斗。土真正落入平台后才增加接收量。
5. 对准新堆积的 Terrain 再挖，可以重新收集回填土。
6. 在普通灰色地面上卸料会生成独立锥形土堆。Backspace 重置本土区的斗量、下落土方、回填、接收区贡献与土堆。

原来的 Demo 2 引用了同一卸料脚本，也会使用新的自由卸土规则；本次另存的 Demo 3 给 Terrain 预留了更大的堆积高度范围。
旧的纯切削 Demo / Demo 1 没有卸料组件，仍适合单独检查切削。

## 这一轮改变

- **出土由斗姿决定。** 斗口向下、或土量超过当前姿态可保留的量时，会在短暂延迟后卸土/撒土。卸料速度随倾角和剩余量变化，不要求下方存在平台。
- **土面随重力调整。** 对标定的斗腔做三维平面裁剪，按体积求解土面高度；允许默认 30 度安息角并平滑过渡。支持俯仰和侧倾，保留的网格体积不因姿态变化而变化。
- **下落有时间和路径。** 土方小批量离斗，以重力轨迹和线段碰撞确定去向。画面里的小土团只有显示网格，不创建大量刚体。
- **车厢按落入量接收。** 配置接收区是落点判断，不是卸料许可。满载后的多余土会从近侧溢出继续下落，不退回铲斗。
- **Terrain 真正堆高。** 回到来源土区时修改运行时高度图和 TerrainCollider，可再次切削。相邻小批土先合并写入，减少高度图量化误差。
- **普通地面留下土堆。** 等体积锥形网格显示累计量，并记录来源。

## 计量与重置

`BucketSoilCutter`：
- `VolumeM3`：斗内当前量。
- `ExcavatedVolumeM3`：累计挖入量，回填后再挖会再次增加。
- `EmittedVolumeM3`：累计离斗量。
- `DeliveredVolumeM3` / `DeliveredMassKg`：累计完成沉积的量与估算质量。
- `Landings`：实际沉积记录，包括仿真时间、目的组件、体积、质量。

`BucketSoilUnloader`：
- `AirborneVolumeM3` / `AirborneMassKg`：尚在下落的土。
- `SurfacePendingVolumeM3`：已抵达 Terrain、等待合并写入高度图的土。

`SoilReceivingZone.Records` 继续记录接收来源、时间、体积与质量；普通地面土堆也使用同一来源账本。

两种口径不能混用：

```
累计挖入 = 当前斗内 + 当前下落 + 待写入Terrain + 累计沉积
Terrain净减少 = 同源各斗当前量 + 下落/待写入量 + 平台当前量 + 独立土堆当前量
```

第二式针对没有外部导入土方、同一来源土区的作业。回填过的土再次挖入时，累计挖入和累计沉积都可能大于地形净减少量。
密度沿用每轮首次切削时捕获的数值，默认 1600 kg/m³；本轮没有加入松散系数和可变土载荷关节力。

Backspace 按来源重置：同一 Terrain 的全部铲斗、在途土和接收贡献一并清理，其他来源在接收区中的土仍保留。
作业期间保持来源土区、密度基准、接收尺寸及组件生命周期不变；切换来源或删除对象前先复位。

## 模型范围

- 这是几何/土量模型与 Unity 关节物理的结合，不是颗粒或连续介质求解器；土流是简化的小土团。
- 回填土高度受 TerrainData 的高度范围限制。最终小于高度图量化单位的余量、达到高度上限的溢出量，会保留为独立土堆，不会从账本抹去。
- 可再次切削的是实际写入 Terrain 的部分；独立网格土堆暂不支持二次挖掘，也不对设备施加土堆碰撞力。
- 外来 Terrain/Cesium 网格按普通地面生成独立土堆，避免按来源复位时破坏另一土区。尚未直接变形 Cesium。
- 接收区要求单位缩放、竖直向上；使用世界竖直重力。接收区满载的溢出路线是近侧边缘的简化处理。
- 没有碰到任何地面的土保留在在途账本，越界很远后冻结等待重置，不凭空清零。无关越界土不会阻塞 Terrain 余量沉积。
- 快速回转惯性撒土、粉尘、真实颗粒堆积/塌落、土载荷反作用仍是后续工作。

本次没有修改 Cesium 主场景，也没有重新导出 Web。Web 性能与构建仍需单独验证。
