# ZX200 Dig Cycle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Space-triggered ArticulationBody digging cycle and normal work-ready startup pose to the generated ZX200 prefab.

**Architecture:** A runtime controller in the existing `ExcavatorControls` assembly resolves and drives four articulation joints through serialized pose phases. A ZX200 editor setup component configures the generated prefab. The generic URDF importer exposes a small editor postprocessor interface so robot-specific setup can run after every re-import.

**Tech Stack:** Unity 6000.5, C#, ArticulationBody, UnityEditor PrefabUtility, NUnit EditMode tests, Unity Test Framework.

## Global Constraints

- Joint motion must update `ArticulationDrive.target`, never visual transforms.
- Work-ready defaults are swing `0°`, boom `-35°`, arm `75°`, bucket `20°`.
- All requested joint targets are clamped to imported drive limits.
- Space starts one cycle and is ignored while startup or motion is active.
- Re-importing ZX200 must leave exactly one configured controller.
