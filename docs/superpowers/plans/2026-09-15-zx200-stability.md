# ZX200 启动姿态与运动稳定性修复

用户已授权修复启动抖动、机械臂与回转抖动，并把编辑器默认姿态对齐运行待机姿态。保留动态底盘和现有操作映射。

## 验证与实施
- [x] 在独立 Unity 6000.5.10f1 项目副本记录启动、实际键盘速度下的倾角、角速度和关节误差。新增启动不大幅甩臂的回归测试；现有测试跳过了启动阶段。
- [x] 修复预制体初始关节姿态：编辑器按关节锚点摆到待机位，保留原始零位和关节限位；启动时仅初始化一次关节状态，后续动作继续由物理求解。
- [x] 根据对照测试处理手动指令突变与求解稳定性；保留重力、碰撞、履带牵引、真实后部配重。避免用不断覆写底盘姿态掩盖问题。
- [x] 添加可重复的编辑器待机姿态更新入口，保存 ZX200 预制体，使依赖它的两个 demo 一致；不覆盖用户场景位置及未保存修改。
- [x] 回归运行关节控制、自动循环、底盘行驶/制动/转向/障碍/无地面与挖土测试，报告实测指标及限制。

## 文件职责
`Zx200DigController.cs` 管理目标与启动状态；`Zx200FixedBasePhysics.cs` 管理关节树、配重和求解配置；`Zx200PrefabSetup.cs` 负责预制体姿态持久化；`Zx200StabilityTests.cs` 验证完整物理行为。测试副本位于 `/home/sk/Unity/zx200-stability-test-20260915`，原始修改文件先备份到该目录外的独立备份目录。

## 已确认的对照数据
原始启动：铲斗关节位移4.666m，底盘倾角7.7578°，角速度0.9165rad/s。只保存Transform姿态不够，必须在Awake同步一次ArticulationReducedSpace。初始化对齐后：倾角0.0523°；重力下动臂实际-47.178°（目标-48°），铲斗剩余0.167m弹性沉降。加入0.3秒目标SmoothDamp后，完整速度反向倾角2.2871°→0.0766°，角速度0.2568→0.0054rad/s；运动幅度测试防止通过不响应输入而获得稳定。
