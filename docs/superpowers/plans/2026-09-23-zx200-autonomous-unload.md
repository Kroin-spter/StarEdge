# ZX200 自主挖掘卸料修复实施计划

> **执行方式：** 本会话内逐项执行并验证。

**目标：** 让 `sence_test` 场景稳定完成连续多斗挖掘、回转、实际卸料、返回和正常停止。

**架构：** 保持现有 `AutonomousExcavationController` 状态机和物理土量账本。复合目标按铲斗、动臂、斗杆、回转拆成单轴物理运动段，每段保持其它关节的实测姿态，并按活动轴反馈确认完成。满斗后先保留实测斗杆姿态抬升到车厢净空，再伸展至车侧工作范围并复验；回转目标按斗尖可达的接收区内部落点搜索，实体净空以碰撞几何及逐物理步检测验收，不能安全到达时停止卸料。车厢按 45° 斜停，接收区与实体底板按可见货厢对齐；多斗循环按可达回转角自动换点。PlayMode 测试逐物理步检查挖掘机与卡车碰撞体无穿透、阶段有序、车厢实际收土且土量账本守恒。

**技术栈：** Unity 6、C#、ArticulationBody、Unity Test Framework。

## 全局约束

- 保留真实切土、斗内土、空中土流、车厢接收区的量守恒，不通过传送或凭空增加土量。
- 带土朝车厢回转与开斗之前必须通过车厢实体净空检查；净空不足时安全停止并显示原因。
- 抬升、回转、卸料对准和返回等动作段逐轴驱动并按实测角度判断；土层内切削采用斗杆与铲斗的协同运动。
- 真实场景 PlayMode 测试每个物理步检查挖掘机连杆与卡车实体碰撞体，不允许穿透。
- Git 提交信息使用中文，作者名为 `shenkai`；不推送远端。
- 不纳入 `Library/`、`Temp/` 等 Unity 生成缓存。
