# 下方停车与卸料衔接 Implementation Plan

> **For agentic workers:** 使用 executing-plans，在当前 preview 工作树内执行，独立测试副本验证。

**Goal:** 矿卡保持下方自然地面高程，挖掘机留在上方，以斜坡衔接，并减少卸料前反复微调。

**Architecture:** 从抬高停车区前的 e622f22 烘焙地形生成下方轻微坡度停车区。矿卡纵轴沿下方停车带，与两车连线垂直，轮胎区域不再跨越连接坡；连接坡只有一个降高剖面，履带核心保持原状。自动流程先依据实测关节预测展开后的开斗落点，协调展开与小回转；已经安全对准则跳过重复动作，失败保留原有有界恢复。

**Tech Stack:** Unity 6 Terrain、ArticulationBody、真实土方接收、Unity Test Runner。
