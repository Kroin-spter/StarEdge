# 手动挖掘切口与防穿透 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 正常斜切/收斗可以挖土，切口不因容量扫描顺序留下尖峰，斗体深入未切土时有约束，同时保留原场景和自动装车。

**Architecture:** 沿用 Terrain 高度图及土量守恒。切削方向以实际刃口扫掠为依据；高度修改统一分配预算；关节目标增加斗壳采样净空约束，不直接写姿态，不全开 Terrain 刚性碰撞。

**Tech Stack:** Unity 6 / ArticulationBody / Terrain / NUnit EditMode、PlayMode。

## Global Constraints

- 不改地图资产、矿卡、串口、自动动作状态机及用户项目设置。
- 原地继续 feat/unity-optional-delivery；已有 manual-acceptance-5JEDMw 副本用于 Unity 验证。
- 保留静止不切、纯抬升不补挖、侧擦/斗背不伪造进土、底面和容量限制。
- 所有削减高度必须纳入实际体积回读；禁止全地图平滑、超容量切削、凭空补土。
