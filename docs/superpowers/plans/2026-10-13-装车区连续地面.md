# 装车区连续地面 Implementation Plan

> **For agentic workers:** 使用 executing-plans 在当前会话按任务执行；测试副本用于真实场景验证。

**Goal:** 消除挖掘机与矿卡之间的断沟，矿卡平缓停靠，保持真实连续挖掘装车。

**Architecture:** 在现有烘焙 Terrain 上局部生成低坡度、柔和边缘的连接土面，保留履带承载核心和前方切削区。停车地面保留轻微坡度而非独立方形台阶；使用真实轮胎底面拟合高度，限制俯仰 5°、侧倾 3°。

**Tech Stack:** Unity 6、TerrainData、Cesium、本地烘焙快照、Unity Test Runner。
