# 满斗侧落与切削交接

用户要求移除新增装饰管路，并修复自动挖掘溢土不明显、切削结束顿挫。

## 修改

- `ExcavatorAppearance.addMechanicalDetails` 默认及场景配置关闭：不生成附加管路和关节装饰，保留材质升级。
- 正常结束切削采用柔和交接，保留关节求解器速度和当前驱动目标；人工接管、急停、接近底面仍立即停止。
- 自动目标填充率从 85% 提高到 95%。收斗速度仍参考预计进土，但小臂减速依据实际填充，避免提前锁住推进。
- 满斗仍保留 12% 的小臂推进权重直至结束单次切削，超出容量的实际切出土由原有侧落通道守恒处理。
- 原切削时限仅在持续实际进土且未达目标时最多延长 2 秒，不新增重复切削动作。
- 土内侧落从邻近土面排出；斗齿已露出地面时保留侧落出口高度，不直接将它压回地表。

## 验证

- 单元验证覆盖正常交接驱动连续性、满斗继续切削与土量守恒、实际/预测填充区别。
- 最终 EditMode 113/113 通过；外观和真实关节速度 PlayMode 2/2 通过。
- 真实物理 prefab 验证正常交接不清零关节速度，紧急取消仍清零；外观不新增机械装饰对象。
- 完整自动装车通过：4 斗实际装入 1.25360m³，正常结束并返回。
- 每斗峰值 0.28352 / 0.31409 / 0.32012 / 0.33587m³，容量 0.33587m³。
- 各斗实际侧落增量 0.00006 / 0.01990 / 0.00272 / 0.16471m³，未伪造额外视觉土量。
- 结果保存在验证副本 `Diagnostics/overflow-handoff-*.xml`。
- 人工真实挖土后切自动验证通过：完成两斗，实际装车 0.304718m³，斗内清空并返回挖掘方向。

填充率是目标而非保证：单次切削遇到底面、没有新土或达到时限时仍可带较少土安全结束。
