# 人工与自动挖掘无缝接管设计

## 目标与边界

人工操作中按一次 `P` 后，系统取得输入所有权；如果斗内已有土，先安全收斗、脱坡、抬升并装入矿车，随后继续自动多斗；空斗则从当前实测姿态安全进入挖点。自动运行中 `Esc` 或新的人工操纵可随时接管，保留当前姿态、土区、斗内和车厢土量。不能把“任意姿态”理解为物理穿模、车厢已满或设备离开工作区时仍强行运动；这些状态必须保持/交还人工并给出可见原因。

## 控制权

以 `AutonomousExcavationController` 为唯一模式所有者。`P` 锁定自动输入并保持当前实测关节目标；如果按键瞬间仍按住操作杆/键，先等待所有人工输入回中，再启动自动动作。解除回中锁后，仅新的人工动作触发自动→人工接管。AZ 的左右履带与四个关节都算人工动作；过期 topic 不算。接管时取消自动关节运动并保持实测姿态，释放底盘锁及临时切削/卸料控制，不清空土量。

## 入口与运动

自动入口读取真实斗量、姿态、车厢余量和施工区状态。斗内有可转运土量时跳过切削，先用实测角度作为初始目标，受控收斗保土，再复用现有 `Lift → SwingToTruck → PrepareDump → Dump → ConfirmDump → ReturnToDig` 段；车厢实际接收量计入本任务，之后再进入原多斗循环。空斗入口先检查斗尖与坡/车的净空并用实测姿态逐轴脱险，然后进入原挖点切削。预先已有穿透、位置不可达或安全姿态无法构造时拒绝自动运动，不改土量。沿用原有动态车厢落点、碰撞和超时保护。

## 验收

PlayMode 在真实 `sence_test` 场景验证：人工挖出可计量的斗土后 `P`，第一斗经抬升、回转、卸料入车，接着至少再自动挖装一斗，最终目标量 `Completed`；空斗非停放姿态切入也能继续；切削、携土回转和卸料时人工接管均立即释放控制，土量守恒；回中锁与 AZ 履带输入的边界测试通过。原 1m³ 多斗闭环测试保持通过，视觉截图/状态序列证实动作实际发生。
