# 坡脚履带平滑回位设计

用户在坡脚可通行地面上人工移动后按 P，挖掘机须用真实履带回到已标定作业位，再接续当前斗或新一斗；不得瞬移、清空土量或越过矿车碰撞保护。

现有故障文字是“回位停滞”，而非“失去地面接触”。当距目标约 1 米、朝向误差约 15° 时，旧控制器在原地转向与边走边转的切换边界附近可能停住。新控制器根据目标在车体前/后方的投影确定行驶方向，分为朝向校准、沿目标行驶、终点精调和制动。朝向控制须有滞回区，不能在单一角度反复切换；进度判定同时考察距离与朝向，原地转向不能被误判为没有进展。实际制动后的姿态采用不超过 0.2 米、3.5° 的容差，并以完整装车碰撞测试确认安全。

扩大允许启动的坡脚走廊，但只允许沿已知安全平台的近距移动；越界、车体与矿车穿透、长时间失去有效接地、超时或人工接管仍立即停车。短暂漏掉接地点可适度宽限，接地检测阈值不得扩大到把悬空履带当成有效支撑。

验收：从比既有测试更远且带约 15° 偏航的人工驾驶位置启动，回位后至少完成一斗装车；前进、倒车、接管和多斗回归继续通过。记录真实停车误差与车厢实收量。
