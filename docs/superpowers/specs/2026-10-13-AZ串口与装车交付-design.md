# AZ 串口与装车交付设计

状态：用户已确认实施。基线 e706757；不修改地形、车辆位置或自动挖掘轨迹。

串口默认 AZ 发布 control_slider_data：left_pedal/right_pedal.value、left_handle.x/y、right_handle.x/y。前端只在 dc_test 演示中转为 action1～6，缺失、非法值默认中位128。不同协议不套用 AZ 映射。Unity 六轴共同采用0.5秒有效期，超时停止；键盘仍可独立控制，人工非中位输入仍能接管自动流程。

装车按钮在 dc_test 使用 BroadcastChannel 定向请求。大屏确认绑定设备、命令时效和 Unity 就绪后，同源转发至 Unity 的 ReceiveAutonomousCommand("start")，由该方法调用 P 键已有 StartAutonomousJob()。重复运行请求不重置流程。不缓存就绪前的启动命令，不改变真实设备 setSynergistic 话题。前端提示只能表示命令已发送，不能冒充施工已完成。

在独立 Unity 副本导出并验证 WebGL；独立 npm 环境构建 Windows x64 NSIS EXE，保留原有许可证与真实ROS配置。软件回放/自动化测试不等同于真实串口或 Windows 实机验收。
