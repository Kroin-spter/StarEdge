# 座舱前端一键导出

保存 `sence_test` 场景并退出 Play，然后选择菜单：

`Tools > Excavator > 导出并更新座舱前端`

默认同步到 `/home/sk/26q1/cockpitWeb/public/unity-webgl`。路径由当前工程位置计算，换电脑后可用 `Tools > Excavator > 设置座舱前端导出目录` 选择现有 `cockpitWeb` 工程。

菜单复用 CesiumWebBuild：构建线程版 WebGL、复制本地地图，成功后同步 Build、TemplateData、maps、StreamingAssets，更新 delivery.json。前端专用 index.html 保留；缺少地图/构建文件或构建失败时不替换前端。

随后在前端目录执行：

```bash
# 默认不带 Unity
npm run electron:pack:win

# 带 Unity
npm run electron:pack:win:unity
```

Linux 交叉打包 Windows EXE 需要 Wine，Node 依赖应在当前系统安装。安装器输出在 cockpitWeb/release。详细验证步骤见前端仓库 `docs/Unity_WebGL导出更新Electron手册.md`。

默认 VITE_ENABLE_UNITY=false；VITE_MAP_RENDERER=ol 仅控制普通地图，与 Unity 开关独立。修改 Unity 脚本/场景后需要重新导出；仅修改 Vue 前端可直接打包。
